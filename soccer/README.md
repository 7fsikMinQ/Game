# 축구 구단 (Soccer)

잉글랜드 · 독일 · 한국 리그 중 하나를 골라 1·2부 승강제 안에서 구단을 키우는 **방치형 축구 감독 게임**.
Football Manager(FM) 계열의 핵심(현재능력 CA / 잠재능력 PA 1~200, 능력치 1~20, 포메이션·전술, 계약·이적·임대·재정)을 **폰에서 몇 번 탭으로** 할 수 있게 줄였습니다.
앱을 닫아도 시간이 흐르고, 열면 그동안의 경기가 한꺼번에 반영됩니다. 인터넷 없이도 열리고 진행 상황은 기기에 저장됩니다.

실행: [../docs/IPHONE-SETUP.md](../docs/IPHONE-SETUP.md) · 설계: [../docs/soccer/DESIGN.md](../docs/soccer/DESIGN.md) · FM과 비교: [../docs/soccer/FM-COMPARISON.md](../docs/soccer/FM-COMPARISON.md) · 실제 데이터: [../docs/soccer/REAL-DATA.md](../docs/soccer/REAL-DATA.md)

## 한눈에

| 리그 | 1부 | 2부 | 강등 | 승격/플레이오프 | 임대 영입 한도 |
|---|---|---|---|---|---|
| 잉글랜드 | 프리미어 리그 20팀, **38라운드** | 챔피언십 24팀, **46라운드** | 3팀 | 2부 1~2위 + 3~8위 6팀 플레이오프(7경기) 우승 | **동시 2명**(공식) |
| 독일 | 분데스리가 18팀, **34라운드** | 2. 분데스리가 18팀, 34라운드 | 2팀 + 16위 승강 PO | 2부 1~2위 + 3위가 1부 16위와 2경기 | 동시 3명(게임 설정) |
| 한국 | K리그1 12팀, 정규 **33라운드 + 파이널 5라운드** | K리그2 17팀, **32경기**(34라운드, 라운드마다 1팀 부전) | 1팀(12위) + 11위 승강 PO | 2부 1위 + 2위가 1부 11위와 2경기 | 동시 3명(게임 설정) |

승점은 모두 **승 3 · 무 1 · 패 0**. 순위는 승점 → 득실차 → 다득점. K리그1은 33라운드 후 상위 6팀(파이널 A)/하위 6팀(파이널 B)으로 나뉘어 각자 5라운드를 더 치르고, **A조 팀이 항상 B조 위**입니다.

규칙 수치는 2026년 10월 기준 공개 자료를 따랐고, 확인하지 못한 것은 "게임 설정"으로 표시했습니다(근거와 한계: [RESEARCH.md](../docs/soccer/RESEARCH.md)).

## 시작하기

1. **리그 선택** → **구단 선택**(강팀·중위·약팀 표시, 1·2부 모두 선택 가능).
2. **방치형 자동 진행**(기본 켜짐): 시즌이 끝나도 멈추지 않고 어시스턴트가 유스·재계약을 처리해 다음 시즌을 시작합니다. 끄면 오프시즌에서 멈춰서 직접 결정합니다.
3. 홈 화면의 **계속 ▶ / 5라운드 / 시즌 끝까지** 로 건너뛸 수 있습니다. 가만히 두면 기본 15분(5/15/30/60분 선택)마다 한 라운드가 자동으로 진행됩니다.
4. (선택) 내 데이터 팩 가져오기: 실제 구단명·선수명·나이를 직접 넣을 수 있습니다 → [REAL-DATA.md](../docs/soccer/REAL-DATA.md).

## 선수 (FM 방식)

- **능력치 24개**(1~20): 기술 9 · 멘탈 6 · 피지컬 5 · 골키퍼 4. 포지션마다 중요한 능력치가 다르고, 그 가중 평균으로 **CA(1~200)** 가 정해집니다.
- **PA(잠재능력, 1~200)** 는 CA의 상한입니다. 훈련으로 능력치를 올려도 PA를 넘는 성장은 취소됩니다.
- **포지션 숙련도**: 스트라이커를 센터백 자리에 세우면 능력치가 낮아 자연히 약합니다(인접 포지션은 보정 0.8~0.97).
- **유망주 등급(★1~4: 기대주/유망주/특급 유망주/세계적 재능)**: 시장·언론의 기대 등급입니다. 등급이 높을수록 PA가 높게 뽑히지만 같은 등급 안에서도 편차가 큽니다. 19~22세에는 대기만성(PA↑)/기대 이하(PA↓)가 일어날 수 있습니다.
  - 18세 중 PA 160 이상 약 1.8%, 180 이상 약 0.3% (자동 테스트가 이 비율을 지킵니다).
- **스카우트 불확실성**: 다른 구단 선수의 PA는 스카우트 수준에 따라 **범위(예: 118~154)** 로만 보이고, 스카우트 10레벨이면 정확합니다. 내 선수는 항상 정확합니다.
- 나이: 어린 선수는 현재 능력이 낮고 빨리 큽니다(17세는 같은 구단 평균보다 CA가 약 33 낮게 생성). 31세부터 속도·민첩·체력이 떨어지고, 34세 이상은 은퇴합니다.
- **컨디션**(경기 후 하락, 라운드마다 회복) · **사기** · **부상**(경기 중 발생, 의무팀이 단축) · **출장정지**(퇴장 다음 경기).

## 경기

- 90분을 분 단위로 굴립니다: 점유 → 찬스 → 슈팅 → 골/선방, 세트피스, 파울·경고·퇴장, 페널티, 부상, 체력 소모, 후반 교체(최대 3명).
- 전력은 **수비/중원/공격 3개 라인**으로 계산하므로 포메이션이 실제로 영향을 줍니다(3백은 수비가 얇은 대신 중원이 두껍다 등).
- 홈 이점 포함. 실측 보정 결과: 경기당 총 득점 EPL 약 2.9 / 분데스 약 3.3 / K리그 약 2.7, 홈 45% 무 23% 원정 32%, 슈팅 약 25, 경고 약 1.9, 부상 약 0.27건, 팀당 교체 3명(상한).
- 앱이 열려 있을 때 끝난 경기는 **분 단위로 중계**(약 8초)됩니다. 건너뛰기를 누르면 바로 결과가 나옵니다.

## 어시스턴트 감독(AI)

| 기능 | 하는 일 |
|---|---|
| 자동 라인업 | 부상·출장정지·피로(컨디션)를 보고 매 경기 베스트11과 벤치를 정함 |
| 포메이션 추천 | 5개 포메이션을 같은 기준으로 평가해 순위를 보여주고 1위를 적용할 수 있음 |
| 경기 예상 | 시뮬레이션 없이 기댓값(푸아송)으로 승/무/패 확률 계산 |
| 자동 재계약 | 필요한 선수만, **재정 한도(선수단 비용 비율) 안에서** 재계약 |
| 유스 | 잠재력 높은 신인을 자동 영입 |
| 상대 AI | 모든 구단이 같은 어시스턴트 로직으로 라인업·포메이션을 짬(6라운드마다 포메이션 재평가) |

LLM(챗봇) 기능은 넣지 않았습니다. 서버나 API 키 없이 **오프라인으로** 돌아가야 하기 때문입니다.

## 돈 (단위: 만 원 / 가상 화폐)

- 수입은 **평판에 지수로 비례**(홈경기 입장 + 스폰서/중계 + 승리 보너스). 연봉도 능력에 지수로 비례해서, 강팀이 항상 적자거나 약팀이 항상 흑자가 되지 않도록 리그·부별로 보정했습니다(구단 평균 연봉/수입 ≈ 0.78).
- **선수단 비용 비율 = (연봉 + 이적료 상각) / 수입**. 잉글랜드는 2026/27부터 시행되는 규정을 단순화해 반영: 85% 초과 시 부담금, 115% 초과 시 승점 6점 삭감(시즌 80% 시점 점검). 독일·한국은 경고만.
- 시즌 상금, 대륙 대회 진출 보상, 강등 시 낙하산 지원금.
- 시설 5종(훈련/유스/경기장/스카우트/의무) Lv0~10.

## 이적 · 임대 · 계약

- **이적시장은 기간이 있습니다**: 오프시즌 + 시즌 초반 5~6라운드(여름), 시즌 중반 5라운드(겨울). 닫혀 있으면 영입·매각·임대를 할 수 없습니다(자유계약과 방출은 가능).
- **영입**: 가치의 1.2배. **매각**: 가치의 0.85배 즉시, 또는 **이적 등록**해서 제안을 기다림(호가 상한 가치의 1.15배, 제안은 호가 이하). 가끔 원치 않는 제안도 옵니다.
- **임대 영입**: 임대료(가치의 6%) + 연봉 부담, 시즌 끝에 복귀, 언제든 **완전 영입 옵션**(가치의 1.1배). 동시 한도는 리그 규칙.
- **임대 보내기**: 임대료를 받고 연봉은 상대가 부담, 시즌 끝에 복귀, 중간에 복귀 요청 가능(받은 임대료 반환).
- **계약**: 선수마다 연봉과 남은 기간. 만료 선수는 오프시즌에 재계약(보너스 + 새 연봉)하지 않으면 떠납니다.
- **자유계약**: 계약 보너스만 내고 데려올 수 있지만 시장에는 "남는 선수"만 나옵니다.
- **되팔이 방지**: 영입한 선수는 19라운드 동안 팔 수 없고, 공짜로 데려온 선수는 가치의 25%만 쳐줍니다.

## 개발자 메뉴(치트)

상단 제목을 **3초 안에 7번 탭**: 시간 배속(x1/10/60/900), 자금 +10억/+100억, 능력치 +2, 전원 회복, 시즌 끝까지. 사용하면 세이브에 표시됩니다.

## 저장

두 칸(A/B) 교대 저장 + 체크섬 + 압축(능력치를 배열로 접음). 한 칸이 깨져도 이전 칸으로 복구. 구단 탭 → 설정 → **백업/복원**(파일 저장·복사). iOS가 웹 데이터를 지울 수 있어서 **10경기 이후 7일마다 백업 알림**이 뜹니다.

## 알려진 한계 (v0.2)

- 실제 구단·선수 데이터는 들어 있지 않습니다(가상). 직접 가져오기는 가능합니다.
- 컵 대회, 대륙 대회 경기, 대표팀, 여자 축구, 선수 개별 훈련·성격·지시, 코치/스태프, 세트피스 편집, 매니저 해고는 없습니다. (FM과 무엇이 다른지: [FM-COMPARISON.md](../docs/soccer/FM-COMPARISON.md))
- 2부가 3부와 이어지지 않습니다(2부 아래는 없음). 승강은 1·2부 사이에서만 일어납니다.
- 이적시장 기간·임대 한도 중 일부(K리그 전체, 독일·한국 임대 한도)는 공식 값을 확인하지 못해 게임 설정으로 둔 값입니다.
- 승격 플레이오프는 시즌 끝에 한 번에 자동으로 치릅니다(내 팀이 포함돼도 중계 없이 결과만).
- 아이폰 실기기에서의 동작은 점검표([IPHONE-SETUP.md](../docs/IPHONE-SETUP.md))로 직접 확인해야 합니다. 이 환경에서는 Chromium(아이폰 크기)까지만 검증했습니다.
