# 야구 규정 반영표 (2026 시즌 기준)

"반영" = 게임에서 규정대로 구현, "단순화" = 취지는 같지만 계산을 줄임, "생략" = 넣지 않음.
출처는 [RESEARCH.md](RESEARCH.md)에 검색 기록과 함께 적었습니다. 규정은 시즌마다 바뀌므로 **확인된 것과 확인하지 못한 것**을 구분해 적었습니다.

## 능력·성장 규칙(게임 고유)
| 항목 | 내용 |
|---|---|
| 능력치 | 20~99. 종합(OVR)은 포지션별 가중 평균(수비 비중: C/SS 22%, CF 20%, 2B 18%, 3B 16%, RF 14%, LF 10%, 1B 7%, DH 0%) |
| 잠재력(POT) | 어릴수록 격차가 크고, 27세 이후 현재 능력에 수렴. ★ 등급에 따라 격차 분포가 다름 |
| 성장 | 매 오프시즌 `(POT-OVR)×계수`(22세 이하 0.33 → 29세 0.1) + 무작위. 30세부터 노화, 33세부터 가속. 훈련 시설 레벨당 +0.15 |
| 정체/늦게 터짐 | 25세 이하에서 매 시즌 각 7% 확률로 POT가 하락/상승 |
| 은퇴 | 투수 41, 타자 42세(능력이 낮으면 37세부터 확률적) |
