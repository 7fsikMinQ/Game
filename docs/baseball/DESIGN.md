# 야구 설계

## 구조 (baseball/src)
| 파일 | 역할 |
|---|---|
| `data.js` | 리그 설정(MLB/KBO 규정 수치, 구단 목록, 시장 규모·시작 전력), 가상 이름 풀 |
| `player.js` | 선수 생성, OVR(종합) 계산, 포지션 감점, 연봉 곡선, 유망주 등급(hype), 성장/노화 `ageUp`, 트레이드 가치 |
| `roster.js` | 라인업/타순/로테이션/불펜 구성, 1군 엔트리 자동 정리 `autoRoster`, 엔트리 검증 |
| `sim.js` | 타석 단위 경기 시뮬레이터(결정적), 리그별 득점 환경 `ENV`, 부상·피로 |
| `league.js` | 구단/선수 생성, 일정 생성, 포스트시즌 대진(시리즈·홈 순서) |
| `core.js` | 상태 공용 도우미: 난수 래퍼, 재정(수입·운영비·예산·경쟁균형세 기준 연봉) |
| `market.js` | 계약(연장·방출), FA, 트레이드(평가·성사), AI 제안, 드래프트, 잠재력 추정 |
| `game.js` | 상태·시즌 진행(`advance`/`playNow`), 포스트시즌, 시즌 종료 정산, 오프시즌, 시설, 개발자 메뉴 |
| `storage.js` | A/B 두 칸 저장 + 체크섬 + 선수 배열 압축 |
| `pack.js` | 실제 데이터 팩(CSV/JSON) 검사·적용 |
| `views.js` / `app.js` | 화면 문자열 생성(순수 함수) / DOM·이벤트·타이머 |

원칙: **상태 = JSON 하나**, 게임 로직은 DOM에 의존하지 않아 Node에서 그대로 테스트합니다. 난수는 시드 하나(mulberry32)로 `withRng` 한 곳에서만 만들어 써서, 앱을 오래 닫았다 열어 몰아서 계산해도 **나눠서 계산한 것과 결과가 똑같습니다**(테스트로 확인).

## 방치(idle) 모델
- `nextGameAt`(다음 경기 시각)만 저장합니다. 앱이 열릴 때 `advance(s, now)`가 지난 시간 ÷ 간격 만큼의 "틱"을 한 번에 처리합니다. 한 틱 = **내 팀의 한 경기**(내 팀이 쉬는 날은 건너뛰고 다른 팀 경기만 진행).
- 한 번에 최대 `MAX_CATCHUP`=200틱(정규시즌 한 번 + 포스트시즌 정도). 더 오래 비웠으면 일부만 반영하고 `skipped`로 알려줍니다.
- 자동 진행이 켜져 있으면 시즌이 끝날 때 `startNextSeason(auto)`가 어시스턴트 로직(만료 선수 재계약, 빈자리 FA, 드래프트 자동 지명)을 돌려 다음 시즌으로 이어갑니다. 꺼져 있으면 오프시즌에서 멈춥니다.
- 건너뛰기(`playNow`)는 시계와 무관하게 n경기를 즉시 진행하고, 시계를 지금부터 다시 시작합니다.
- 계산 속도(측정): 한 시즌(전 구단 2,430경기) 약 0.3초, 200틱 따라잡기 약 0.4~0.6초(MLB).

## 경기 엔진
타석마다 하나의 난수로 결과를 고릅니다: 삼진 → 볼넷 → 홈런 → 인플레이 안타(BABIP) → 땅볼(병살 포함) → 뜬공(희생플라이 포함).
- 확률은 타자(컨택·파워·선구·주력)와 투수(구위·제구, 피로 시 -10), 수비(팀 수비 평균)로 계산: 예) 삼진률 `0.205 + env.k + (구위-50)×0.0042 - (컨택-50)×0.003`.
- 주자 진루는 주력으로 가감(안타 때 2루→홈, 1루→3루 등).
- 선발은 투구 수 한도(체력 기반)나 실점이 많으면 교체. 9회 3점 차 이내 리드 상황에는 마무리가 먼저 등판. 크게 앞서거나 뒤지면 약한 불펜을 씁니다.
- 선발 5명은 휴식일(`rest`)이 가장 긴 순서로 등판. 구원 투수는 투구 수만큼 피로가 쌓이고 하루 12씩 회복되어 55를 넘으면 쉽니다.
- 기록: 타자 PA/AB/H/2B/3B/HR/RBI/BB/K/R, 투수 G/GS/아웃/ER/H/BB/K/HR/W/L/SV(세이브는 구원 투수가 3점 차 이내 리드를 지켰을 때).
- **리그별 환경(`ENV`)**: 실제 평균에 맞춘 보정값. MLB 팀당 약 4.5점, 삼진 22%, 볼넷 8.6%, 홈런 2.9%, 홈 승률 약 52%. KBO 팀당 약 4.9점, 삼진 20%, 볼넷 9.3%, 홈런 2.7%, 무승부 약 2.5%. (테스트가 범위를 검증)
- 팀 능력 1점 차이가 승률 약 +3%p. 팀 승률 표준편차 약 7%p(MLB 실제와 비슷).

## 능력과 성장
- 능력치 20~99. 타자 OVR은 포지션별 수비 비중을 가중(수비 중요 포지션일수록 수비 반영), 투수는 선발이면 체력 22%, 구원이면 5%.
- 잠재력: 생성 시 `POT = OVR + 격차`, 격차는 나이(어릴수록 큼)와 유망주 등급(★)으로 결정. 등급별 기본 격차 범위: ★0 8~17, ★1 12~22, ★2 17~28, ★3 24~36, ★4 31~44 (×0.42 ×(25-나이)/6).
- 성장: `ΔOVR = (POT-OVR)×계수 + N(0,1.6)`, 계수는 22세 이하 0.33, 24세 0.26, 26세 0.2, 29세 이하 0.1. 30세부터 감소(30세 -0.3, 31세 -0.6, 32세 -1.2, 33세 -1.8…).
- 25세 이하 7%는 정체(POT 하락), 7%는 늦게 터짐(POT 상승).
- 이 수치는 **리그 전체 평균 능력(약 52~55)과 평균 나이(약 27)가 15년 동안 유지되도록** 장기 시뮬레이션으로 맞췄습니다(분석 문서 참고).

## 재정
- 연 수입 = `rev0 × 시장 규모 × (0.8 + 0.4×인기/100) × (1 + 0.04×구장 레벨)` (MLB rev0=300 $M, KBO 700억).
- 비용 = 연봉 총액 + 운영비(수입 × (1 − 예산비율 − 0.07)) + 시설 유지비. 기준 연봉 예산 = 수입 × 예산비율(MLB 55%, KBO 22%).
- 내 팀의 경기마다 `(수입 − 비용)/경기 수`를 정산하고, 포스트시즌 홈경기는 추가 수입, 우승/진출 보너스는 시즌 종료 때 지급. 사치세·경쟁균형세도 시즌 종료 때 차감.
- 시작 연봉 총액은 구단 예산 근처로 맞춰 생성(MLB 5~7팀이 사치세 초과, KBO는 상한 이내 — 실제 시작 상황과 비슷).
- 자금이 마이너스면 FA 영입·시설 투자가 막히고 경고가 표시됩니다.

## 시장
- **연봉 곡선**: `시장 연봉 = base × e^(k×(OVR-50))`, 최저연봉~상한으로 자르고 34세 이상은 할인. (MLB base 4.0 $M, k 0.0863 / KBO base 2.8억, k 0.085)
- **계약**: 서비스 연차에 따라 구단 보유(프리 아브·연봉조정 단계) → FA 자격(MLB 6년/KBO 8년). 만료 시 보유권 선수는 자동 갱신, FA 자격 선수는 사용자가 재계약하지 않으면 FA 시장으로.
- **FA**: 오프시즌에 요구 연봉 = 시장 연봉 ×1.08(외국인 ×1.15), 시즌 중에는 ×0.78. 영입한 선수는 2군으로 들어오며 25일간 거래 불가(영입 후 되팔기 악용 방지).
- **트레이드**: 선수 가치 = `10×e^{0.1×(OVR+성장여지-50)}×나이계수×(구원 0.6)` + 계약 잉여(시장 연봉 - 연봉)×잔여 연수. 한 번에 여러 명을 줄 때는 가장 가치 높은 선수만 100%, 나머지는 60%로 계산. 상대가 **1.1배 이상** 받아야 수락. 로스터·외국인·연봉 부담 한도 확인.
- **AI 구단**: 오프시즌에 만료 선수 재계약(가치·예산 기반) 후 남는 선수는 FA로, 예산 여유가 있는 팀이 가치 순으로 영입. 구단 구성(포수 2명·선발 6명 이상)을 지키며 모자라면 대체 선수를 채움. 가끔 내 선수에 대한 트레이드 제안을 보냄.
- **드래프트**: 성적이 나쁜 팀부터. 후보는 18~22세, ★ 등급 확률(0 45%, 1 30%, 2 16%, 3 7%, 4 2%). 내 차례에 직접 지명하거나 자동 지명.
- **스카우트 불확실성**: 다른 팀·신인의 POT는 `±오차` 범위로 표시(오차 = 12 - 1.2×스카우트 레벨, 최소 2). 선수 id로 고정된 오차라 새로고침해도 안 흔들립니다.

## 저장
- 두 칸(`bb.save.a/b`)에 번갈아 저장, 칸마다 체크섬. 쓰는 도중 꺼져도 직전 칸이 온전합니다.
- 선수를 배열로 접고 기본값을 생략해 용량을 줄임: MLB 시즌 중 약 340KB, 10시즌 후 약 400KB, KBO 약 160~220KB.
- 포맷이 다른 게임(옛 야구단 v1, 축구) 저장은 거절하고 새로 시작합니다.
