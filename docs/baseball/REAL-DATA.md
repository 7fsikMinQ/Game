# 실제 선수 데이터 가져오기 (이름·나이·포지션·능력·유망주)

## 왜 기본에는 실제 선수가 없나
1. **정확성**: 2026 시즌의 실제 로스터·나이·계약은 시즌 중에도 계속 바뀝니다. 제가 가진 정보로 선수 명단을 쓰면 틀린 선수가 들어갈 수 있고, 이 환경에서는 선수 DB 웹페이지에 직접 접속할 수 없었습니다(검색 요약만 가능).
2. **저작권/초상권 문제 회피**: 공개 저장소(GitHub Pages)에 실제 선수 이름+능력치 DB를 올리면 상업 이용이 아니어도 선수 이름·성과 데이터에 대한 권리/약관 문제가 생길 수 있습니다. 개인이 자기 기기에서만 쓰는 것과는 다릅니다.
3. 대신 **내가 구한 데이터를 내 기기 안에서만 불러오는 기능**을 넣었습니다. 데이터는 저장소에 올라가지 않습니다.

구단 이름은 단순 사실(공개된 팀 이름)이라 기본 포함입니다.

## 사용법
1. 시작 화면 → **데이터 팩 가져오기**.
2. CSV를 붙여 넣거나 파일 선택 → **검사하기** → 문제가 없으면 **이 데이터로 새 게임 만들기**.
3. 구단 선택 화면으로 넘어갑니다. 구단 이름이 맞으면 해당 구단의 가상 선수가 실제 선수로 **자리를 바꿉니다**.

PC에서 미리 검사하려면: `node tools/make-pack.mjs 내데이터.csv` (구단 이름이 미리 채워진 빈 양식: `node tools/make-pack.mjs --teams mlb > mlb.csv`).

## CSV 열
`league,team,name,pos,birth,ovr,pot,hype,salary,years,fx` (순서 무관, 헤더 필수, 쉼표/탭 구분, 한글·영문 헤더 일부 허용)

| 열 | 의미 | 필수 |
|---|---|---|
| league | `mlb` 또는 `kbo` | 첫 줄만 있으면 됨 |
| team | 구단 이름(한글·영문·약어·별명 모두 인식. 예: `뉴욕 양키스`, `Yankees`, `NYY`, `LG`, `트윈스`) | ✔ |
| name | 선수 이름(24자까지) | ✔ |
| pos | `C 1B 2B 3B SS LF CF RF DH SP RP` (한글 `포수 선발 구원` 등과 `OF IF P CP LHP RHP`도 변환) | 권장 |
| birth / age | 생년월일(2026-10-08 기준 나이 계산) 또는 나이 | 권장 |
| ovr | 이 게임의 종합 능력(20~99). 평균 주전 약 56, 올스타급 70~75, 리그 최고 85 안팎 | 아래 참고 |
| show | MLB The Show 류의 OVR(40~99). `ovr = 0.9×(show-40)+33`으로 환산 | 대체 |
| pot | 잠재력(20~99). 없으면 나이·hype로 생성 | 선택 |
| hype | 유망주 등급 0~4(23세 이하에만 적용) | 선택 |
| salary | 연봉(MLB $M, KBO 억 원) | 선택 |
| years | 계약 잔여 연수 | 선택 |
| fx | KBO: `1`=외국인, `2`=아시아쿼터 | 선택 |

**능력치가 없으면**: ovr → show → 연봉(연봉 곡선을 거꾸로 계산) → 구단 평균 근처 무작위 순서로 추정합니다.

## 어디서 구하나 (사용자가 직접)
- MLB: Baseball-Reference / FanGraphs / Baseball Savant의 팀 로스터·나이·연봉(Spotrac). OVR이 필요하면 게임사(MLB The Show 등)가 공개한 평점을 `show`로 쓸 수 있습니다.
- KBO: KBO 공식 기록실(koreabaseball.com)의 팀 로스터·선수 정보, Statiz, 나무위키 구단 페이지 등.
- 이용 약관(재배포 금지, 자동 수집 금지)을 지켜서 개인적으로 정리하세요. 그 CSV를 저에게 붙여 주시면 이 형식으로 바꿔 드릴 수 있습니다.

## 적용 규칙
- 선수 수가 모자라면 나머지는 가상 선수로 남습니다(권장: 구단당 26명 이상). 팩에 있는 선수는 같은 포지션(없으면 같은 역할) 중 가장 비슷한 능력의 가상 선수와 교체됩니다.
- 이름이 겹치는 가상 선수는 없어도 됩니다(경기 로직은 id로 구분).
- 한 번 적용한 데이터는 저장 파일에 포함됩니다(백업에도 들어갑니다). 새 게임을 시작하면 다시 가져와야 합니다.
- **개인용으로만** 쓰고 공개 저장소에 올리지 마세요(`private/` 폴더는 `.gitignore`에 들어 있습니다).
