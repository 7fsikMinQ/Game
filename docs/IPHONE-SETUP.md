# 아이폰에서 실행하기 (처음부터 끝까지)

노트북(Windows)에서 코드를 받고 → 테스트하고 → 아이폰에서 열고 → 홈 화면에 추가하는 전체 순서입니다.
**Mac, Apple 개발자 계정, USB 연결, 앱 설치(사이드로딩)는 필요 없습니다.**

> 두 가지 방법이 있습니다.
> - **방법 A (지금 바로 해보기)**: 노트북에서 서버를 켜고, 같은 Wi-Fi의 아이폰이 접속. 5분. 테스트용.
> - **방법 B (평소에 쓰기)**: 인터넷(HTTPS)에 한 번 올려두면 노트북 없이 아이폰만으로 실행, 오프라인도 지원. → [DEPLOY.md](DEPLOY.md)
>
> A로 동작을 확인하고, 마음에 들면 B로 옮기는 순서를 권장합니다.

---

## 0. 준비물 (한 번만)

| 항목 | 설치 방법 (PowerShell) | 확인 |
|---|---|---|
| Node.js 20 이상 (LTS) | `winget install OpenJS.NodeJS.LTS` 또는 https://nodejs.org 에서 LTS 설치 | `node -v` 가 v20 이상 |
| Git | `winget install Git.Git` | `git --version` |

설치 후 PowerShell을 **새로 열어야** 명령이 인식됩니다.

Git을 쓰기 싫으면: GitHub 저장소 페이지에서 `claude/serene-franklin-tpdu4g` 브랜치를 고르고 **Code → Download ZIP** 으로 받아 압축을 풀어도 됩니다. USB로 폴더를 옮겨도 똑같이 동작합니다(`node_modules` 같은 게 없는 폴더 하나입니다).

## 1. 코드 받기

```powershell
git clone https://github.com/7fsikMinQ/Game.git
cd Game
git checkout claude/serene-franklin-tpdu4g
```

이미 받아둔 상태라면:

```powershell
cd Game
git fetch origin
git checkout claude/serene-franklin-tpdu4g
git pull origin claude/serene-franklin-tpdu4g
```

## 2. 자동 테스트 먼저 돌리기 (선택이지만 권장)

```powershell
npm test
```

마지막에 `pass 61 / fail 0` 이 나오면 정상입니다. 윈도우에서는 `test.bat` 더블클릭도 같습니다.
(`npm install`은 필요 없습니다. 의존성이 없습니다.)

## 3. 방법 A — 노트북에서 서버 켜고 아이폰으로 접속

### 3-1. 서버 실행

```powershell
npm start
```

(또는 `start.bat` 더블클릭.) 이런 화면이 나옵니다.

```
  이 PC에서      http://localhost:8080/baseball/
  아이폰(같은 Wi-Fi)  http://192.168.0.23:8080/baseball/
```

- **Windows 보안 경고**(방화벽)가 뜨면 **"개인 네트워크 허용"** 을 누르세요. 이걸 막으면 아이폰이 접속하지 못합니다.
- 먼저 노트북 브라우저에서 `http://localhost:8080/baseball/` 를 열어 게임이 보이는지 확인하세요.
- 서버를 끄려면 `Ctrl+C`.

### 3-2. 아이폰에서 열기

1. 아이폰을 **노트북과 같은 Wi-Fi** 에 연결합니다. (노트북이 핫스팟이면 그 핫스팟에 연결)
2. **Safari**에서 위에 출력된 `아이폰(같은 Wi-Fi)` 주소를 입력합니다. 예: `http://192.168.0.23:8080/baseball/`
3. 첫 화면에 `도원 야생마`가 보이고 다음 경기 카운트다운이 돌면 성공입니다.

안 열릴 때:
- 주소 앞부분이 `192.168.` / `10.` / `172.16~31.` 로 시작하는 것을 고르세요. 여러 줄이 나오면 Wi-Fi 쪽 주소를 씁니다. 모르겠으면 PowerShell에서 `ipconfig` 로 "무선 LAN 어댑터 Wi-Fi"의 IPv4 주소를 확인하세요.
- 카페/학교/공용 Wi-Fi는 기기끼리 통신을 막는 경우가 많습니다. 휴대폰 핫스팟에 노트북을 붙이거나 집 Wi-Fi에서 하세요.
- 노트북의 방화벽 허용을 놓쳤다면 Windows 설정 → 방화벽 → 앱 허용에서 Node.js를 개인 네트워크에 허용하세요.
- 포트 충돌 시: `$env:PORT=8081; npm start`

### 3-3. 홈 화면에 추가

1. Safari 하단(또는 주소창 옆)의 **공유 버튼(□에 ↑)** 을 누릅니다. 안 보이면 **⋯ 메뉴 → 공유** 로 들어갑니다.
2. **홈 화면에 추가** 를 누릅니다.
3. **웹 앱으로 열기** 스위치가 있으면 **켭니다.**
4. **추가**. 홈 화면에 공이 그려진 "야구단" 아이콘이 생깁니다.

이제 아이콘으로 실행하면 주소창 없이 전체 화면으로 열립니다.
(메뉴 이름은 iOS 버전에 따라 조금 다를 수 있습니다.)

### 3-4. 방법 A의 한계 (꼭 읽어 주세요)

주소가 `http://`(암호화 안 됨)라서 iOS가 **서비스 워커(오프라인 캐시)를 허용하지 않습니다.**

- 홈 화면 아이콘으로 실행해도 **노트북 서버가 켜져 있어야** 앱이 열립니다.
- 저장 데이터는 이 주소(`192.168.x.x:8080`)에 묶입니다. **방법 B의 주소로 옮기면 데이터가 새로 시작**됩니다. 옮기려면 구단 탭 → **백업 / 복원** 을 쓰세요(아래 6번).
- 게임 시간 계산 자체(닫아둔 동안의 경기 반영)는 A에서도 정상 동작합니다. 서버가 켜져 있기만 하면 됩니다.

## 4. 동작 확인 점검표 (아이폰)

테스트를 빠르게 하려면 숨김 개발자 메뉴를 쓰세요. 위쪽 "야구단" 제목을 **3초 안에 7번** 탭하면 열립니다. (자세한 건 [baseball/README.md](../baseball/README.md))

| # | 확인 | 기대 결과 |
|---|---|---|
| 1 | 앱을 연다 | 카운트다운이 줄어든다. 하단 탭 4개가 보인다 |
| 2 | 개발자 메뉴 → 배속 x60 | 10초에 한 경기씩 진행, 경기마다 전광판에 득점·중계 로그가 나온다 |
| 3 | **[핵심] 닫아둔 동안 진행** — 배속을 x1로 되돌리고 앱을 완전히 닫은 뒤(앱 전환 화면에서 위로 밀기) **11분 뒤** 다시 연다 | "자리를 비운 동안 1경기 진행 · …" 카드가 뜬다 |
| 4 | 배속 x60 상태에서 앱을 닫고 2분 뒤 연다 | 여러 경기가 한꺼번에 반영되고 순위/자금이 바뀐다 |
| 5 | 선수단 → 선수 → 능력치 옆 금액 버튼 | 자금이 줄고 능력치 +1 |
| 6 | 개발자 메뉴 → 시즌 끝까지 | 오프시즌 화면(우승팀, 드래프트)이 뜬다 → 다음 시즌 시작 |
| 7 | 홈 화면 아이콘으로 다시 실행 | 진행 상황이 그대로 유지된다 |
| 8 | 어두운 모드 전환(설정 → 디스플레이) | 화면이 어두운 테마로 바뀐다 |
| 9 | (방법 B 이후) 비행기 모드 켜고 실행 | 앱이 열린다 |

3번이 이 설계의 핵심입니다. 이 동작은 실제 아이폰에서 직접 확인해야 하는 항목입니다.

## 5. 코드가 바뀌었을 때 반영하기

노트북에서 `git pull` 후 서버가 켜져 있으면, 아이폰에서 앱을 닫았다 다시 열면 됩니다. (서버는 캐시를 쓰지 않습니다.)
방법 B에서는 [DEPLOY.md](DEPLOY.md)의 "업데이트" 절을 보세요.

## 6. 데이터 백업과 옮기기

iOS는 오래 안 쓴 웹 데이터를 지울 수 있습니다. 홈 화면에 추가한 앱은 비교적 안전하지만 보장은 아닙니다.

- 구단 탭 → **백업 / 복원** → **파일로 저장**(공유 시트에서 "파일에 저장"을 고르면 iCloud Drive에 남습니다) 또는 **복사**(메모 앱 등에 붙여넣기)
- 복원: 같은 화면에서 붙여넣기 후 **복원**, 또는 **파일에서 복원**
- 방법 A에서 B로 옮길 때도 이 백업/복원을 쓰면 됩니다.

## 7. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 아이폰에서 사이트에 연결할 수 없음 | 같은 Wi-Fi인지, 방화벽 허용했는지, 주소에 `/baseball/` 까지 썼는지 확인 |
| 화면이 안 바뀜(예전 화면) | Safari 새로고침. 홈 화면 앱은 완전히 닫았다 다시 열기. 그래도 안 되면 설정 → Safari → 방문 기록 및 웹 사이트 데이터 지우기(**세이브도 지워지니 백업 먼저**) |
| 시간이 안 흐르는 것 같음 | 카운트다운은 앱이 열려 있을 때만 움직입니다. 닫아둔 동안의 경기는 다시 열 때 반영됩니다 |
| 오프시즌에서 멈춤 | 정상입니다. 시즌 사이에는 직접 "다음 시즌 시작"을 눌러야 합니다 |
| 데이터가 사라짐 | 주소가 바뀌면(IP 변경, A→B 이동) 저장 공간이 다릅니다. 백업/복원 사용 |
| `npm` 인식 안 됨 | Node.js 설치 후 PowerShell을 새로 열기. 정 안 되면 `node tools/serve.mjs` 로 직접 실행 |
| `npm test`가 실패 | 출력의 `✖` 줄을 확인. 해결 안 되면 그 로그를 그대로 알려주세요 |
