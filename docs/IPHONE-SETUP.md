# 아이폰에서 실행하기 (처음부터 끝까지)

**Mac, 개발자 계정, USB 연결, 앱 설치(사이드로딩)는 필요 없습니다.** 웹앱(PWA)을 홈 화면에 추가해서 씁니다.

두 가지 방법이 있습니다.

| | 방법 B (권장): 인터넷에 올리기 | 방법 A: 노트북 서버로 테스트 |
|---|---|---|
| 노트북 필요 | **없음**(GitHub 웹에서 설정, 아이폰만으로 가능) | 켜져 있어야 함 |
| 오프라인 | **됨**(한 번 열어 두면) | 안 됨(http라서 서비스 워커 불가) |
| 시간 | 약 10분(처음 한 번) | 약 5분 |
| 용도 | **평소에 쓰기** | 코드 고치면서 확인 |

---

## 방법 B — GitHub Pages (가장 쉬운 방법)

이 저장소는 **공개(public)** 라서 GitHub Pages가 **무료**입니다. 배포 설정(`.github/workflows/pages.yml`)은 이미 들어 있고, 푸시하면 테스트를 돌린 뒤 자동 배포합니다.

> **알아둘 점**: 이 저장소의 기본 브랜치는 `main`이 아니라 `claude/serene-franklin-tpdu4g` 입니다. 이전 버전의 배포 설정은 `main`에서만 돌도록 되어 있었고, GitHub에서 확인한 결과 **워크플로 실행 기록이 0건**이었습니다. 지금은 두 브랜치 모두에서 돌도록 고쳤습니다.

### B-1. GitHub에서 Pages 켜기 (한 번만, 아이폰 Safari로도 가능)

1. https://github.com/7fsikMinQ/Game → **Settings → Pages**
2. **Build and deployment → Source** 를 **GitHub Actions** 로 선택.
3. **Actions** 탭 → 왼쪽 **Deploy to GitHub Pages** → **Run workflow** (브랜치: `claude/serene-franklin-tpdu4g`) → 실행.
   - 이 코드를 푸시하면 자동으로도 실행됩니다. 처음에 Pages가 꺼져 있어서 실패했다면 B-1의 2번을 한 뒤 **Re-run** 하세요.
4. 1~2분 뒤 초록색 체크가 뜨면 완료. 주소:
   - 축구: `https://7fsikminq.github.io/Game/soccer/`
   - 야구: `https://7fsikminq.github.io/Game/baseball/`
   - 목록: `https://7fsikminq.github.io/Game/`

### B-2. 아이폰에서 설치

1. 아이폰 **Safari**로 위 주소를 엽니다. (다른 브라우저가 아니라 Safari)
2. 공유 버튼(□↑) 또는 **⋯ 메뉴 → 공유 → 홈 화면에 추가**.
3. **웹 앱으로 열기** 스위치가 있으면 **켜고** → **추가**. (iOS 26부터는 어떤 사이트든 기본으로 웹앱으로 열리지만, 오프라인은 이 앱이 따로 지원하는 기능입니다.)
4. **홈 화면의 아이콘으로 실행**합니다. 첫 실행은 **인터넷이 켜진 상태**에서 한 번 열어 두세요(파일을 저장하는 시간).
5. **오프라인 확인**: 비행기 모드를 켜고 아이콘으로 실행 → 열리면 성공.

### 꼭 지킬 것: 설치한 아이콘으로만 플레이하기

- Safari 탭에서 하던 진행 상황은 **설치한 앱으로 이어지지 않는다**는 보고가 있습니다(저장소가 분리됨, 공식 확인은 못 함). 설치 후에는 **아이콘으로만** 플레이하세요.
- Safari 탭에서 이미 하던 게임을 옮기려면: 구단 탭 → 설정 → **백업/복원** → 백업(복사 또는 파일) → 설치한 앱에서 **복원**.
- iOS는 **7일간 쓰지 않은 사이트의 웹 데이터를 지울 수 있습니다**. 홈 화면 앱이 면제인지는 공식 확인이 안 됐습니다. 앱이 영구 저장을 요청하고 **7일마다 백업 알림**을 띄우지만, **가끔 백업 파일을 "파일" 앱(iCloud Drive)에 저장**해 두는 것이 가장 안전합니다.

### 업데이트 받기

코드를 고쳐서 푸시하면 자동 배포됩니다. 앱은 **온라인일 때 열 때마다 최신 파일을 받습니다**(네트워크 우선 + 오프라인 대비 저장). 앱을 **완전히 닫았다가 다시 열면** 새 버전이 반영됩니다. 그래도 안 바뀌면 앱을 지우고 다시 추가하세요(**먼저 백업**).

## 방법 A — 노트북에서 서버 켜서 테스트 (선택)

### A-0. 준비물 (한 번만, 윈도우 PowerShell)

| 항목 | 설치 | 확인 |
|---|---|---|
| Node.js 20 이상 | `winget install OpenJS.NodeJS.LTS` | `node -v` |
| Git | `winget install Git.Git` | `git --version` |

설치 후 PowerShell을 **새로 열어야** 합니다. Git이 싫으면 GitHub에서 **Code → Download ZIP** 으로 받아도 되고, USB로 폴더를 옮겨도 똑같이 동작합니다(의존성 없음).

### A-1. 받기

```powershell
git clone https://github.com/7fsikMinQ/Game.git
cd Game
git checkout claude/serene-franklin-tpdu4g
```

### A-2. 테스트 → 서버

```powershell
npm test        # 마지막에 fail 0 이면 정상 (또는 test.bat 더블클릭)
npm start       # 서버 실행 (또는 start.bat 더블클릭)
```

출력 예: `아이폰(같은 Wi-Fi)  http://192.168.0.23:8080/soccer/`

- Windows 방화벽 경고가 뜨면 **"개인 네트워크 허용"**.
- 아이폰을 **노트북과 같은 Wi-Fi**에 연결하고 Safari로 그 주소를 엽니다.
- 안 열릴 때: 같은 Wi-Fi인지, 방화벽 허용했는지, 주소 끝에 `/soccer/`(또는 `/baseball/`)를 썼는지, 카페·학교 Wi-Fi는 기기 간 통신을 막는지 확인. 포트 충돌은 `$env:PORT=8081; npm start`.

### A-3. 한계

주소가 `http://`라서 **오프라인 캐시가 안 되고**, 노트북 서버가 꺼지면 앱이 열리지 않습니다. 저장 데이터는 이 주소에 묶여 **방법 B 주소로 옮기면 새로 시작**됩니다(백업/복원으로 옮기기).

## 점검표 (아이폰 실기기)

이 환경에서는 Chromium(아이폰 크기)까지만 검증했습니다. 아이폰에서 직접 확인해 주세요. 빠르게 보려면 **개발자 메뉴**(상단 제목을 3초 안에 7번 탭)의 시간 배속 x60/x900을 쓰세요.

### 축구 구단

| # | 확인 | 기대 결과 |
|---|---|---|
| 1 | 앱을 연다 → 리그 선택 → 구단 선택 | 3개 리그, 1·2부 구단 목록. 고르면 홈 화면 |
| 2 | 홈에서 **계속 ▶** | 8초 정도 분 단위 중계 → 결과, 전광판, 점유율/슈팅 |
| 3 | **5라운드** / **시즌 끝까지** | 즉시 진행, 순위가 바뀜 |
| 4 | 전술 탭 → 선수 탭 → 다른 선수 선택 | 피치에 반영, 자동 라인업이 꺼짐 |
| 5 | 구단 탭 → 이적 → 선수 → 영입 | 자금 감소, 선수단 +1, 소식에 기록 |
| 6 | **[핵심] 닫아둔 동안 진행**: 간격을 5분으로 바꾸고 앱을 완전히 닫은 뒤 **11분 뒤** 열기 | "자리를 비운 동안 2라운드 진행 …" 카드 |
| 7 | 시즌 끝까지 진행 → 오프시즌/다음 시즌 | 순위, 승강, 상금, 유스/재계약. 방치형이 켜져 있으면 자동으로 다음 시즌 |

| 9 | 설정 → 백업 → 파일로 저장 | 공유 시트에서 "파일에 저장" |
| 10 | 어두운 모드 전환 | 화면이 어두운 테마로 바뀜 |

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| Pages 설정이 안 보임 / Actions가 실패 | Settings → Pages 에서 Source가 **GitHub Actions** 인지. 저장소가 공개인지(공개 아님이면 유료 플랜 필요) |
| `Get Pages site failed` | Pages를 켜기 전에 돌았음 → B-1의 2번 후 Re-run |
| 아이폰 주소가 404 | 주소 끝의 `/Game/soccer/` 대소문자(저장소 이름 `Game`), 배포가 끝났는지 Actions 확인 |
| 앱이 예전 화면 | 앱을 완전히 닫았다 열기. 안 되면 지우고 다시 추가(**백업 먼저**) |
| 진행 상황이 사라짐 | 주소가 바뀌었거나(A→B, 도메인 변경), Safari 탭과 설치 앱의 저장소가 다름, iOS의 웹 데이터 삭제 → **백업/복원** |
| 시간이 안 흐르는 것 같음 | 카운트다운은 앱이 열려 있을 때만 움직입니다. 닫아둔 동안의 경기는 다시 열 때 반영됩니다 |
| 열 때 몇 초 멈춤 | 오래 비웠다 열면 최대 120라운드를 계산합니다("계산 중" 화면) |
| 오프시즌에서 멈춤 | 방치형 자동 진행이 꺼져 있음(설정에서 켜기) |
| `npm`이 인식 안 됨 | Node.js 설치 후 PowerShell을 새로 열기. 안 되면 `node tools/serve.mjs` |
| `npm test` 실패 | 출력의 `✖` 줄을 그대로 알려주세요 |
