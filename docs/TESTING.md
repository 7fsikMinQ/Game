## 1. 자동 테스트 (`npm test`)

Node 내장 테스트 러너(`node:test`)를 씁니다. 설치할 것이 없습니다. `tools/test.mjs` 가 `*/test/*.test.mjs` 를 전부 찾아서 실행합니다.

```powershell
npm test                                    # 전체
node --test baseball/test/sim.test.mjs      # 파일 하나만
node --test --test-name-pattern="끝내기" baseball/test/sim.test.mjs   # 이름으로 하나만
```

성공하면 맨 아래에 `ℹ pass 61` / `ℹ fail 0`, 실패하면 `✖` 와 어떤 값이 기대와 달랐는지 나옵니다.

### 무엇을 검증하나

| 파일 | 검증 내용 |
|---|---|
| `rng.test.mjs` | 같은 시드는 같은 수열, 상태 저장 후 이어쓰기, 정규분포 |
| `sim.test.mjs` | 팀 구성(타자9·선발5·구원3), 능력치 범위, 같은 시드는 같은 경기, **불변식**(무승부 없음·이닝 합=점수·끝내기·15회 제한), 개인 기록 합계=팀 기록, 선발 5인 로테이션과 구원 등판, **밸런스**(팀당 득점 3.6~5.6, +10 팀 승률 60~85%) |
| `season.test.mjs` | 일정(팀당 42경기·상대 6회·홈 21경기), 시간 경과별 경기 수, **오프라인 몰아서 진행 = 조금씩 진행(결정성)**, 200경기 상한, 시계 역행, 한 시즌 전체·포스트시즌·오프시즌, 10시즌 연속 안정성, 순위 정렬 |
| `economy.test.mjs` | 훈련(비용·한계·자금 부족·남의 선수), 시설, 드래프트(계열 제한·1회), 스카우트 효과, 개발자 메뉴, **장기 밸런스**(5시즌 동안 투자하는 구단이 방치 구단보다 확실히 강하되 무적은 아님) |
| `storage.test.mjs` | 저장/불러오기, A/B 교대 저장, **마지막 칸이 깨졌을 때 복구**, 체크섬, 용량 초과·사생활 보호 모드, 백업 왕복, 세이브 크기 |
| `views.test.mjs` | 모든 단계에서 모든 화면이 `undefined`/`NaN` 없이 렌더, 중계 중 스포일러 가림, **XSS 방지**(이름에 `<script>`), 서식 함수 |

### 테스트를 믿어도 되는 범위

- 규칙과 수치는 시드 고정이라 **매번 같은 결과**입니다. 실패하면 우연이 아니라 코드가 바뀐 것입니다.
- 밸런스 테스트는 **범위**로 검사합니다(예: 득점 3.6~5.6). 수치를 일부러 바꿨다면 이 범위를 같이 조정하세요.
- 화면 *모양*은 자동 테스트가 못 봅니다. 그건 2번과 3번의 몫입니다.

## 2. 브라우저 스모크 테스트 (`npm run smoke`)

실제 Chromium으로 `http://localhost:8123/baseball/` 를 아이폰 16 Pro 비슷한 화면(393×852)에서 밝은/어두운 테마 각각 돌립니다.

확인하는 것: 홈 렌더, 경기 중계와 스코어보드, 훈련으로 자금 감소, 개발자 메뉴(제목 7번 탭), 시즌 종료→오프시즌→다음 시즌, **새로고침 후 저장 유지**, **오프라인 로드(서비스 워커)**, 콘솔 에러 없음.
스크린샷은 `tools/.shots/` 에 저장됩니다(git 제외). 디자인 확인에 그대로 쓰세요.

**playwright가 필요합니다** (이 저장소의 의존성이 아닙니다):

```powershell
npm i -g playwright
npx playwright install chromium
npm run smoke
```

## 3. 아이폰 수동 점검

[IPHONE-SETUP.md](IPHONE-SETUP.md) 4절의 표를 따라 하세요. 특히 **"앱을 닫아둔 동안 경기가 반영되는가"** 는 iOS에서만 확인할 수 있습니다.
빠르게 보려면 개발자 메뉴의 **배속 x60** (경기 간격 10분 → 10초)을 쓰세요. 점검이 끝나면 x1로 되돌리거나 새로 시작하세요.

## 문제를 재현하는 법

게임은 시드(`state.seed`)와 난수 상태(`state.rng`)가 세이브에 들어 있어서 **결정적**입니다.
버그를 발견하면 구단 탭 → 백업 → 복사한 텍스트를 전달하면, 같은 상태에서 같은 일이 재현됩니다.
Node에서 직접 재현하려면:

```js
import { newGame, advance } from './baseball/src/game.js';
const s = newGame(1234, 1_700_000_000_000);
advance(s, 1_700_000_000_000 + 600_000 * 42);   // 10분 간격으로 42경기
console.log(s.teams.map(t => [t.name, t.w, t.l]));
```
