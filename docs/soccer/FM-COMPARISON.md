# Football Manager(FM23~FM26)와 비교

**원칙**: FM은 PC에서 수십 시간 들여 하는 정밀 시뮬레이션이고, 이 게임은 **폰에서 몇 번 탭으로, 앱을 닫아도 진행되는 방치형**입니다. 그래서 "FM에서 매일 해야 하는 일"은 **어시스턴트가 대신하거나 없앴고**, "FM을 FM답게 만드는 핵심 숫자 체계"는 그대로 가져왔습니다.

참고한 버전: **FM23, FM24, FM26**(FM25는 2025-02 취소 → [RESEARCH.md](RESEARCH.md)). FM의 데이터·코드·이름은 복사하지 않았고, 공개된 개념과 커뮤니티 가이드(CA/PA 1~200, 능력치 1~20)만 참고했습니다.

## 모바일/방치형으로 FM보다 나은 점 (의도)

- **앱을 닫아도 시즌이 진행**되고, 열면 요약 카드(몇 라운드, 승무패, 자금 변화, 소식)가 뜸.
- **인터넷 없이** 열리고 진행 상황은 기기에 저장(백업 가능).
- **어시스턴트에게 맡기기**: 오프시즌 유스·재계약·다음 시즌 시작까지 자동.
- **건너뛰기**: 경기 하나, 5라운드, 시즌 끝까지, 중계만 건너뛰기.
- 경기 전 **승/무/패 예상**으로 전술 변경의 효과를 바로 확인.
