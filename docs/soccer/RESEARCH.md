**결론**: 이름 자체를 개인 기기에서 쓰는 것은 문제될 가능성이 낮지만(법률 자문 아님), (1) **정확한 선수 명단·나이를 이 환경에서 확보할 수 없고**(페이지 접근 불가, 이적시장마다 바뀜), (2) 공개 저장소·공개 URL에 실제 선수 이름을 올리면 위 판례·분쟁과 같은 위험 영역이라서, **앱에는 넣지 않고 사용자가 직접 가져오는 방식**으로 풀었습니다 → [REAL-DATA.md](REAL-DATA.md).

## 6. iPhone 웹앱 (저장·오프라인)

| 사실 | 상태 | 출처 |
|---|---|---|
| Safari는 **7일간 상호작용이 없는 사이트의 스크립트 저장소(localStorage, IndexedDB, 서비스 워커 등록)를 지울 수 있음**. 홈 화면에 추가한 웹앱이 면제인지는 **공식 확인 안 됨**(포럼에서는 면제라는 주장, 한 실험은 localStorage 유지·쿠키 삭제) | ❌/🟡 | [Apple 포럼](https://developer.apple.com/forums/thread/710157) · [WebKit 저장소 정책](https://webkit.org/?p=14403) |
| `navigator.storage.persist()` 로 영구 저장 요청 가능(포럼 보고: 효과는 있으나 앱을 열 때마다 요청해야 함) | 🟡 | 같은 포럼 |
| **iOS 26부터 Safari에서 홈 화면에 추가한 사이트는 기본적으로 웹앱으로 열림**(추가 시 "웹 앱으로 열기" 토글) | ✅ | [heise](https://heise.de/-10749652) · [iThinkDiff](https://www.ithinkdiff.com/add-web-app-bookmark-iphone-home-screen-ios-26/) |
| 오프라인은 서비스 워커를 등록해야만 됨(웹앱으로 열리는 것과 별개). **서비스 워커는 HTTPS에서만** 등록됨 | ✅ | [firt.dev](https://firt.dev/notes/pwa-ios/) |
| Safari 탭의 저장 데이터가 홈 화면 앱으로 **이어지지 않는다**는 2026년 보고(저장소 분리) | 🟡 단일 출처 | [Habr](https://habr.com/en/articles/989862) |
| iOS 26.1에서 설치된 PWA가 전체 화면으로 안 보이는 버그 보고(iOS 18.6에서도 재현) | 🟡 | [WebKit 버그](https://bugs.webkit.org/show_bug.cgi?id=301994) |

→ 게임의 대응: 저장은 localStorage + 앱을 열 때마다 `persist()` 요청 + **7일마다 백업 알림** + 파일/복사 백업. **홈 화면 앱으로 처음 연 뒤부터 플레이**하고, Safari에서 하던 것을 옮기려면 백업/복원을 쓰도록 안내했습니다.
