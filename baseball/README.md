# 야구단

구단을 하나 맡아 선수를 키우고 시설에 투자해서 우승을 노리는 방치형 게임.
**앱을 닫아도 경기가 진행**되고, 다시 열면 그동안의 결과가 한꺼번에 반영됩니다.

실행 방법: [../docs/IPHONE-SETUP.md](../docs/IPHONE-SETUP.md)

## 플레이 방법

1. **경기 탭**: 다음 경기까지 카운트다운(기본 10분). 경기가 끝나면 전광판과 득점 장면이 나옵니다. 앱이 열려 있을 때 끝난 경기는 한 타석씩 중계되고, 닫아둔 동안의 경기는 "자리를 비운 동안" 카드로 요약됩니다.
2. **선수단 탭**: 타자/투수 목록(숫자는 종합 능력치). 선수를 누르면 능력치별로 **돈을 내고 +1 훈련**. 능력치 막대의 가는 주황 선이 **잠재력(한계)** 입니다. 이름도 바꿀 수 있습니다.
3. **순위 탭**: 8팀 순위표. 상위 4팀이 포스트시즌(단판 토너먼트)에 진출. 역대 우승팀 기록.
4. **구단 탭**: 자금과 시설 투자.
   - **구장**: 홈경기 수입 +20% / 레벨
   - **훈련장**: 훈련 비용 -6% / 레벨, 시즌 후 성장 보너스
   - **스카우트**: 신인 후보의 능력·잠재력 상승
   - 설정: 경기 간격(5/10/20/30분), 팀 이름, 백업/복원, 새로 시작
5. **시즌이 끝나면 오프시즌**: 시즌 보상을 받고, 신인 3명 중 한 명을 영입(같은 계열 선수 한 명이 나감)하거나 건너뛰고 다음 시즌을 시작합니다. 시즌이 넘어갈 때 모든 선수가 나이를 먹고 능력치가 변합니다(젊으면 성장, 30대 중반부터 하락, 38세 은퇴).

팁: 처음엔 팀이 평균보다 약합니다(의도). 능력치를 올릴 때는 **잠재력 한계 근처가 아닌 선수**, 그리고 **타선/선발 평균을 끌어올리는 쪽**이 효율적입니다. 구장은 장기 수입, 훈련장은 훈련이 많을수록 이득입니다.

## 개발자 메뉴 (치트)

화면 위쪽 **"야구단" 제목을 3초 안에 7번 탭**하면 열립니다.

| 항목 | 동작 |
|---|---|
| 시간 배속 x1 / x10 / x60 / x600 | 경기 간격을 나눕니다. x60이면 10분 → 10초 |
| 자금 +1,000만 / +1억 / +10억 | 자금 추가 |
| 능력치 +5 | 내 팀 전원의 능력치(와 필요하면 잠재력)를 +5 |
| 10경기 즉시 | 지금 바로 10경기 진행 |
| 시즌 끝까지 | 포스트시즌까지 즉시 끝내고 오프시즌으로 |

사용하면 세이브에 `dev.used = true` 가 기록되고 구단 탭에 "개발자 메뉴를 사용한 저장 데이터"라고 표시됩니다.
다른 게임용 트레이너/치트 앱은 이 게임에 쓸 수 없습니다. 아이폰 웹앱은 외부에서 메모리나 저장 데이터를 건드릴 수 없습니다. (백업 텍스트는 체크섬 때문에 직접 고쳐도 복원되지 않습니다.)

## 밸런스 조정 위치

| 바꾸고 싶은 것 | 파일 / 위치 |
|---|---|
| 득점이 너무 많다/적다, 홈런·삼진 비율 | `src/sim.js` `rates()` |
| 선발이 일찍 내려간다 | `src/sim.js` `makeSide()` 의 `limit`, `relief()` |
| 경기 수입, 인기 | `src/game.js` `gameIncome()`, `recordUserGame()` |
| 훈련 비용 | `src/game.js` `trainCost()` |
| 시설 비용/효과 | `src/game.js` `FAC_BASE`, `FAC_INFO`, `gameIncome()`, `progress()` |
| 시즌 보상 | `src/game.js` `finishSeason()` |
| 시작 팀 전력 (내 팀 / AI 팀) | `src/league.js` `createLeague()` 의 `mean` |
| 시즌 길이 | `src/league.js` `makeSchedule(ids, cycles)` — cycles=6 → 42경기 |
| 한 번에 반영하는 최대 경기 수 | `src/game.js` `MAX_CATCHUP` |
| 선수 성장/노화 | `src/game.js` `progress()` |

수치를 바꾼 뒤에는 `npm test` 로 밸런스 테스트(득점 범위, 투자 효과)가 여전히 통과하는지 확인하세요. 테스트 범위를 의도적으로 바꾸는 경우엔 `test/sim.test.mjs`, `test/economy.test.mjs` 의 숫자도 같이 조정합니다.

## 알려진 한계 (v0.1)

- 타순과 투수 로테이션은 자동입니다. 직접 짜는 기능은 아직 없습니다.
- 승·패 투수 판정은 근사치이고, 자책점과 비자책점을 구분하지 않습니다.
- 도루, 번트, 수비 실책, 대타/대주자, 부상은 없습니다.
- 트레이드, FA, 연봉 개념이 없습니다. 선수는 드래프트와 훈련으로만 바뀝니다.
- 기록은 시즌 단위만 보관합니다(통산 기록 없음, 역대 우승팀만 기록).
- 실제 아이폰 16 Pro에서의 동작 확인은 아직 직접 하지 못했습니다. [점검표](../docs/IPHONE-SETUP.md)로 확인해 주세요.
- 이름은 전부 가상입니다(실제 구단/선수와 무관).
