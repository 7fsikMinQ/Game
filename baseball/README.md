# 야구단 (MLB · KBO)

MLB 또는 KBO 구단을 맡아 로스터·계약·트레이드·FA·드래프트·재정을 운영하는 **방치형 야구 매니지먼트** 게임입니다.
앱을 닫아도 설정한 간격(기본 10분)마다 한 경기씩 진행되고, 다시 열면 그동안의 결과가 한꺼번에 반영됩니다.
**건너뛰기**(7경기 / 시즌 끝까지)와 **자동 진행**(시즌이 끝나면 어시스턴트가 재계약·FA·드래프트를 처리하고 다음 시즌 시작)을 지원합니다.

- 규정 반영표: [../docs/baseball/RULES.md](../docs/baseball/RULES.md)
- 설계(엔진·경제·성장): [../docs/baseball/DESIGN.md](../docs/baseball/DESIGN.md)

| 트레이드 마감 | 시즌 약 2/3 지점(실제 2026: 8/3) | 시즌 약 70% 지점(실제 2026: 7/31) |
| 드래프트 | 5라운드(단순화) | 11라운드, 성적 역순 |

구단 이름은 2026 시즌 실제 구단입니다. 선수는 **웹 검색으로 근사한 주요 선수(이름은 한 글자씩 변형, 능력은 성적·평판으로 판단한 근사값) 약 585명 + 가상 선수**입니다. 시작 화면에서 끌 수 있습니다. 직접 구한 CSV는 데이터 팩으로 가져옵니다(REAL-DATA.md).

## 화면

- **경기**: 다음 경기 카운트다운, 선발 투수 비교와 승률, 건너뛰기, 직전 경기 전광판(앱이 열려 있을 때 끝난 경기는 한 타석씩 중계), 소식, 최근 결과. 오프시즌에는 재계약·드래프트·FA 안내.
- **선수단**: 타자 / 투수 / 2군 / 라인업. 1군↔2군 이동, 타순·수비 포지션 직접 지정, 선발 로테이션·불펜 피로 확인. 선수를 누르면 능력치·잠재력·계약·기록.
- **리그**: 순위(MLB는 AL/NL 지구별 + 와일드카드 레이스), 기록 리더, 포스트시즌 대진, 역대 기록.
- **시장**: 트레이드(양쪽 3명까지, 상대가 가치를 평가) · FA · 외국인(KBO) · 드래프트 · AI 구단의 제안.
- **구단**: 재정(수입·연봉·예산·사치세/경쟁균형세), 시설 투자, 설정(경기 간격·자동 진행·백업·초기화).

## 능력치

- 타자: 컨택 · 파워 · 선구 · 주력 · 수비 (20~99). 포지션마다 수비 비중이 다르고, 본포지션이 아닌 자리를 보면 수비 감점이 있습니다(포수·유격수는 특히 큼).
- 투수: 구위 · 제구 · 체력. 선발은 체력 비중이 큽니다.
- **종합(OVR) / 잠재력(POT)** 모두 최대 99. 다른 팀 선수의 잠재력은 스카우트 수준에 따라 **범위**로 보입니다.
- **유망주 등급(★ 1~4)**: 어린 선수에게 붙는 시장의 기대치. 별이 많을수록 잠재력이 높게 분포하지만 모두 크는 것은 아닙니다(정체/늦게 터짐 가능).

## 개발자 메뉴

구단 탭의 **"구단" 제목을 3초 안에 7번 탭**: 시간 배속, 자금 추가, 능력치 +5, 10경기 즉시, 시즌 끝까지. 쓰면 저장 데이터에 표시됩니다. 외부 트레이너 앱은 이 게임에 통하지 않습니다(웹 앱은 외부에서 메모리·저장 데이터를 건드릴 수 없고, 백업 텍스트는 체크섬이 있어 직접 고쳐도 복원되지 않습니다).

## 밸런스 조정 위치

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 득점·삼진·볼넷·홈런·홈 이점 | `src/sim.js` `ENV` (리그별), `rates()` |
| 선발/구원 교체, 피로, 부상률 | `src/sim.js` `relief()`, `rollInjury()` |

| 수입·예산·사치세/경쟁균형세 | `src/data.js` `rev0 / budgetShare / cbtBands / cap`, `src/core.js` |

수치를 바꾼 뒤에는 `npm test` 로 득점 환경/승률 분포/장기 시뮬레이션 테스트가 통과하는지 확인하세요.

## 알려진 한계 (v2)

- 내장 명단은 주요 선수만(팀당 14~17명) 근사한 것이라 소속·나이·능력이 틀릴 수 있고, 나머지는 가상 선수입니다. 정확한 데이터는 데이터 팩으로 가져오세요.
- 도루·번트·대타/대주자·수비 실책·구장별 파크 팩터·좌우 매치업·투구 수 단위 중계는 없습니다(타석 단위 시뮬레이션).
- 트레이드는 선수끼리만(드래프트 지명권·현금 없음). MLB 드래프트는 5라운드로 줄였고 룰5·국제 FA·옵션 제도는 없습니다.
- KBO FA 등급제(A/B/C 보상선수·보상금)와 상무/경찰청 입대, 육성선수 제도는 단순화/생략했습니다.
- 상세 규정과 단순화 이유는 docs/baseball/RULES.md.
